Camelia - MINI

Solution large bande en bande C miniature pour applications professionnelles

Présentation

Camelia - C est une solution large bande en bande C conçue pour les applications pour drones, offrant une bulle de communication de 500m.

Grâce à son architecture compacte et modulaire, elle offre une intégration simplifiée et un déploiement rapide sur le terrain. Son format miniaturisé permet son emport par un soldat sous toutes conditions.

Caractéristiques principales

  • 📡 Fonctionnement en bande C
  • 📶 Architecture large bande
  • ✈️ Masse inférieure à 2 Kg
  • ⚡ Portable par un soldat
  • 🧩 Conception modulaire et évolutive
  • 🚁 Compatible avec les applications drones
